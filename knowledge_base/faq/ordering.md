# Cara Pemesanan dan Minimum Order

**Tanya:** Bagaimana cara memesan Nasi Kotak?
**Jawab:** Anda bisa memesan melalui chat ini dan admin kami akan menindaklanjuti pesanan Anda. Kami akan meminta detail seperti jumlah box, paket yang dipilih, alamat pengiriman, dan tanggal acara.

**Tanya:** Berapa minimum order untuk Nasi Kotak?
**Jawab:** 
- Paket Hemat: Minimum order 20 box.
- Paket Corporate: Minimum order 30 box.
Untuk pesanan di bawah jumlah tersebut, mohon maaf saat ini belum dapat kami layani.

**Tanya:** Berapa hari sebelumnya saya harus memesan (Lead Time)?
**Jawab:** Kami sarankan pemesanan dilakukan maksimal H-2 atau 2 hari sebelum acara. Untuk pemesanan dalam jumlah besar (di atas 100 box), sebaiknya maksimal H-4 agar persiapan lebih matang. Pemesanan mendadak (H-1) tergantung pada ketersediaan slot dapur kami.
