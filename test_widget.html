Halaman Uji Coba Widget Chatbot

Halaman ini mensimulasikan website WordPress yang telah dipasangi script widget.js. Anda dapat melihat tombol chat mengambang (*floating button*) di pojok kanan bawah.

💡 Cara Menguji Tampilan Widget:

  • Perhatikan tombol mengambang (floating button) oranye di pojok kanan bawah layar.
  • Klik tombol tersebut untuk membuka pop-up jendela obrolan AI dari widget.js.
  • Isi nama & nomor WhatsApp (atau klik lewati jika ada tombol lewati).
  • Coba lakukan percakapan, tanyakan menu rekomendasi, reservasi meja, atau menu best seller untuk menguji tampilan balon chat, tombol outlet, dan tombol WhatsApp.
ℹ️ Backend API Target: Widget ini terhubung ke server lokal http://127.0.0.1:8000.

📦 Rincian Elemen Widget (`widget.js`):

Widget ini membawa tampilan mandiri yang mencakup:

  • Floating Button: Tombol bulat dengan ikon pesan di sudut kanan bawah.
  • Chat Window Popup: Header bertema Ayam Bakar Pak D, area percakapan interaktif, dan kotak input pesan.
  • Interactive Buttons: Tombol pemilihan 5 outlet terdekat.
  • Action Link: Tombol konfirmasi langsung ke WhatsApp Admin.
